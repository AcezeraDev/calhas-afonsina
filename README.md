# Calhas Afonsina — site

Front-end do site da Calhas Afonsina (calhas, rufos, coifas e dutos no Grande ABCD).

React + Vite + TypeScript, Tailwind CSS v4, React Three Fiber (cenas 3D), GSAP ScrollTrigger + Lenis (animações de rolagem) e componentes Magic UI.

## Rodar

```bash
npm install
npm run dev
```

Build de produção: `npm run build` (saída em `dist/`).

## Notas

- Apenas front-end: o formulário de orçamento abre o WhatsApp da empresa com a mensagem pronta.
- `public/img/ai/hero-chuva-calha.webp` e `chapas-dobradas.webp` são imagens geradas (ilustrativas). `obra-*-tratada.webp` são fotos reais de obras com nitidez e cor corrigidas.
